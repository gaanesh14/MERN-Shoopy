A fully functional E-Commerce Web Application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js) with features like user authentication, product management, shopping cart, payments, and admin control.

🚀 Features
🛍️ Storefront (Frontend – React)
Responsive modern UI
Browse products by category
Product details page
Search and filtering
Add to cart
Checkout page
User profile and orders page
